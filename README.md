Pump.fun paper-trading bot built by an AI agent for make.fun's Pump.fun Paper Sprint bounty, $2 in USDC. A launch sniper: it watches each coin from creation and buys only launches where the creator put in at least 0.5 SOL of their own money, at least six distinct non-creator wallets have already bought in, and the creator has not sold. One shot per coin, 0.3 SOL staked (capped at 1% of real reserve), with a +25% take-profit, -15% stop-loss, a 10-slot max hold, and an immediate exit on a creator sell. Fully deterministic — no clock, environment, or randomness.

## Run it

```sh
node --experimental-strip-types main.ts
```
